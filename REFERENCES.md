# References

Upstream projects and browser-platform references used to define OmniEmu's runtime and roadmap:

- EmulatorJS — https://github.com/EmulatorJS/EmulatorJS — browser RetroArch frontend; OmniEmu currently pins runtime data to 4.2.3.
- EmulatorJS options/control mapping — https://emulatorjs.org/docs/options/ and https://emulatorjs.org/docs4devs/control-mapping/
- `coi-serviceworker` — https://github.com/gzuidhof/coi-serviceworker — cross-origin isolation fallback for static hosts without custom response headers.
- WebGPU API — https://developer.mozilla.org/en-US/docs/Web/API/WebGPU_API
- Flycast WASM — https://github.com/nasomers/flycast-wasm — 2026 Dreamcast WebAssembly/JIT work and candidate generation-6 adapter.
- Play! — https://github.com/jpd002/Play- — PlayStation 2 emulator with an experimental browser build.
- Dolphin — https://github.com/dolphin-emu/dolphin — GameCube/Wii reference implementation.
- xemu — https://github.com/xemu-project/xemu — original Xbox reference implementation.
- Xenia — https://github.com/xenia-project/xenia — Xbox 360 reference implementation.
- RPCS3 — https://github.com/RPCS3/rpcs3 — PlayStation 3 reference implementation.
- Cemu — https://github.com/cemu-project/Cemu — Wii U reference implementation.

This repository contains emulator frontend code and metadata only. Commercial game images and proprietary console system files are not included.
