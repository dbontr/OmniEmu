# References

OmniEmu is an independent Rust/WebAssembly emulator. These sources define browser contracts or hardware behavior used by the implementation.

## Browser platform

- [WebAssembly Specification 3.0](https://webassembly.github.io/spec/core/) — WebAssembly Community Group; 3.0. Used for: WebAssembly module, memory, numeric, validation, and execution semantics for `omnicore.wasm`.
- [WebAssembly Web API](https://webassembly.github.io/spec/web-api/) — WebAssembly Community Group. Used for: browser instantiation and JavaScript/WebAssembly integration.
- [WebGPU](https://www.w3.org/TR/webgpu/) — W3C GPU for the Web Working Group. Used for: the preferred browser framebuffer renderer and GPU resource rules.
- [WebGL 2.0 Specification](https://registry.khronos.org/webgl/specs/latest/2.0/) — Khronos Group. Used for: the fallback framebuffer renderer.
- [Web Audio API](https://www.w3.org/TR/webaudio/) — W3C Web Audio Working Group. Used for: AudioWorklet-first audio delivery and Web Audio fallback scheduling.
- [Gamepad API](https://www.w3.org/TR/gamepad/) — W3C Web Applications Working Group. Used for: browser gamepad button and axis acquisition.
- [File API](https://www.w3.org/TR/FileAPI/) — W3C Web Applications Working Group. Used for: local `File` and `Blob` range reads that hydrate demand-paged media.
- [Vite HTML features](https://vite.dev/guide/features.html#html) — Vite project. Used for: preserving the classic COOP/COEP service-worker bootstrap with the supported `vite-ignore` HTML opt-out while bundling module application code.

## Verification rule

Hardware behavior must be confirmed by primary documentation or independent tests where practical. A third-party emulator is a differential reference, not a runtime dependency or compatibility claim.

- [JaCzekanski ps1-tests](https://github.com/JaCzekanski/ps1-tests) — JaCzekanski et al.; MIT. Used for: external PlayStation hardware-conformance coverage across CPU, DMA, GPU, GTE, MDEC, SPU, timers, input, and CD-ROM, including the zero-SP direct-loader requirement.
