# OmniEmu Roadmap

The goal is one increasingly complete emulator, not a launcher for separate emulator products. Every milestone preserves the single `omnicore.wasm` runtime invariant.

## Stage 0 — universal kernel foundation

Established:

- One Rust/WebAssembly emulator binary and one browser bridge.
- Permanent platform-id namespace for generations 1–8.
- Deterministic event scheduler and exact rational clock-domain conversion.
- 64-bit physical interconnect plus a 16–64-bit paged MMU with permissions and mapping generations.
- 256-source interrupt controller and generic DMA engine.
- JIT-neutral IR, per-ISA code cache, MMU-generation validation and invalidation primitives.
- 29 active hardware blueprints spanning generations 1–8; PS4/Xbox One are reserved but out of scope.
- Typed chunked resources for game/disc/BIOS/firmware/keys/NAND/storage, bounded live paging for large media, and sparse block storage.
- Bounded GPU command queue plus generation-aware shader translation/cache foundation.
- Unified video, audio, input, error, reset and machine lifecycle ABI.
- Versioned platform-tagged save-state codec.
- Browser WebGPU-first/WebGL 2 fallback video, AudioWorklet-first/Web Audio fallback audio, and Gamepad input paths.
- Direct release-WASM smoke tests in the normal build.
- Runnable ROM-less generation-1 machines: Magnavox Odyssey discrete logic and Home Pong/Telstar class.
- Atari 2600 development graph: shared 6502/6507 addressing, RIOT RAM/I/O/timer, color-clocked TIA graphics/collisions/audio, WSYNC, joystick/fire, RC-timed paddle input, XG-1 light-gun trigger/beam sensing, save states, and 2K/4K, F8/F6/F4, SuperChip, E0, E7, 3E, 3E+, 3F, EF/EFSC, DF/DFSC, BF/BFSC, SB, classic DPC, FE, UA, F0 and FA cartridge hardware.

- Reusable NMOS 6502 execution substrate with the official set, common stable undocumented families, and selectable decimal arithmetic for NMOS versus NES-class behavior.

## Stage 1 — finish the first cartridge families

The NES development graph is launchable but remains `foundation`. Finish it before claiming broad compatibility:

1. Complete APU fidelity with residual frame/DMC IRQ race cases and analog-output detail beyond the implemented NTSC/PAL/Dendy rate profiles and 90 Hz/440 Hz high-pass plus 14 kHz low-pass chain.
2. Complete PPU edge behavior with cycle-faithful internal OAM read/evaluation timing, the remaining sub-cycle CPU/PPU register races, and region-specific electrical/video nuances beyond the implemented NTSC/PAL/Dendy frame timing.
3. Expand board coverage beyond the current discrete/MMC1/MMC1A/MMC2/MMC3/MMC4/MMC5/RAMBO-1/TxSROM/TQROM/CNROM-185/Taito-X1-005/Taito-X1-017/VRC1/VRC2/VRC3/VRC4/VRC6/VRC7/Jaleco-SS88006/Jaleco-JF13-86/Jaleco-JF17-JF19/Irem-H3001/Irem-G101/Irem-TAM-S1/Taito-TC0190/Bandai-FCG-LZ93D50/Datach-157/Bandai-74161-32/Mapper78-Holy-Diver-Uchuusen/Oeka-Kids-96/Sunsoft-2/Sunsoft-3/Sunsoft-4/FME-7/Namco-108/NAMCOT-3425/Namco-163/Namco-175-340/NINA-03/06/HES-NTD8/Camerica-Quattro set, prioritizing additional expansion-audio and licensed specialty hardware, including Jaleco JF-13/JF-17/JF-19 uPD7756C sample playback and Oeka Kids tablet input. Continue validating MMC5's rare detector/electrical edge behavior, N163 and VRC7 audio mixing, RAMBO-1/TxSROM IRQ and CIRAM routing, and TQROM mixed CHR ROM/RAM behavior against legal software.
4. Complete the remaining unstable NMOS 6502 electrical opcode cases, bus-visible timing details, and NES 2.0 board/submapper edge behavior.
5. Expand the automated legal/homebrew compatibility corpus with visual/audio/state determinism and browser performance gates.

Atari 2600, Atari 5200 and Atari 7800 now have launchable development graphs. Atari 2600 covers the principal legacy 2K/4K, F-series, SuperChip, E0/E7, 3E/3E+, 3F, EF/EFSC, DF/DFSC, BF/BFSC, SB, classic DPC, FE, UA, F0 and FA cartridge families; remaining cartridge work is concentrated in modern coprocessor hardware such as DPC+ and related ARM-assisted schemes. Continue timing, display and peripheral compatibility in the shared 6502-family substrate; Atari 7800 cartridge-profile coverage includes valid Bankset EXFIX/BANK6 and fails closed on spec-invalid Bankset EXROM/X2 combinations. Header-selected NTSC/PAL timing is live, leaving cycle-faithful MARIA DMA/modes, CoreTone/BupChip audio, PAL palette/overscan fidelity, and remaining peripherals as the main 7800 gaps.

## Stage 2 — generations 2 through 4

Every active generation-1 through generation-4 target now has a runnable machine graph inside the same OmniCore build. The reusable CPU set for this range includes NMOS 6502, Z80, CP1610, HuC6280, W65C816, SPC700, Motorola 68000 and SH-2. Remaining Stage 2 work is compatibility depth rather than missing machine breadth:

- Refine ColecoVision and Intellivision timing, remaining controller/profile edge cases, non-Intellicart cartridge metadata, and optional peripherals.
- Refine Master System timing and compatibility. The core covers Sega ROM/SRAM plus Codemasters, Korean `$A000`, MSX/Nemesis and Janggun cartridge banking; console Pause/Reset inputs; Mode 4 background/sprite priority, left-column blanking and SMS2 224/240-line geometry/V-counter behavior; legacy Graphics I/II, Text and Multicolor rendering with sprite/status handling; line-timed Mode 4 sprite collision/overflow status; TH-latched H-counter reads; dual-port Light Phaser TL trigger and optical TH sensing; and an FM-capable YM2413 path with nine melodic channels, rhythm output and Japanese-SMS PSG/FM mixing controls. Remaining depth includes PAL regional master/frame timing, cycle/analog-accurate YM2413 envelopes/phase/rhythm and `$F2` C-Sync counter behavior, rarer Korean/multicart mapper variants, other optional peripherals, and tighter raster/status timing.
- Refine SNES S-DSP register polling/KON-KOFF latency, echo/DAC clock timing and cycle-faithful HDMA scheduling. The S-DSP provides BRR decoding, four-point Gaussian interpolation, PMON pitch modulation, hardware-counter-scheduled noise and ADSR/GAIN envelopes, per-voice echo sends, echo RAM, eight-tap FIR, echo volume and feedback. DSP-1 is integrated across its small/large-LoROM and HiROM layouts with command streaming, arithmetic/trigonometry, matrix transforms, projection/raster operations and deterministic state; DSP-2 is integrated across its documented LoROM data-port mirrors with bitmap conversion, transparent overlay, reverse, multiply, scaling and deterministic state; DSP-3 is integrated across its `$20-$3F/$A0-$BF:$8000-$FFFF` LoROM data/status windows with coordinate/movement, verified data-ROM streaming, planar conversion, bitstream decode, path-search operations and deterministic state. S-RTC is integrated through `$2800/$2801`, cycle-driven calendar progression, deterministic state and dedicated persistent storage. Bit-exact DSP-1 projection/inverse edge behavior remains. The PPU covers BG1-BG4 modes 0-6, native 512-pixel modes 5/6 and pseudo-hires presentation, modes 2/4/6 offset-per-tile scroll overrides, mode 3/4 BG1 direct color, core OBJ rendering/priority with 32-sprite and 34-sliver scanline budgets, OAM priority rotation and X=-256 counting behavior, persistent STAT77 range/time-over latches, Mode 7 affine/EXTBG rendering, per-BG 1-16-pixel mosaic, main/sub-screen BG/OBJ windows with two-window logic, main-screen color-window blacking, and fixed/subscreen add/subtract/half color math with color-window transparency masking; remaining video depth is concentrated in exact mosaic/HDMA scanline timing, per-dot STAT77 assertion timing/errata, raster timing, and additional enhancement chips.
- Refine Genesis VDP/DMA/YM2612 timing and cartridge hardware; deepen Sega CD CDC/CDD/stamp-map/multitrack support and 32X SH-2 peripheral/video/PWM timing.
- Refine PC Engine / TurboGrafx CD-ROM behavior with hardware-validated ADPCM/fader timing, exact SCSI/CD-DA timing, CHD media and broader System Card variants; expand remaining specialty HuCard/accessory profiles and tighter video/audio timing.
- Refine SuperGrafx VDC/VPC dot timing, window/priority edge behavior, CD expansion integration, remaining specialty cartridge/accessory profiles and representative compatibility coverage.
- Expand Neo Geo with YM2610 FM fidelity, protected cartridge hardware, raw-set assembly and exact raster timing.

Expansion chips are devices inside the loaded machine graph. They never select a different browser emulator.

## Stage 5 — seventh and eighth generations

Every active seventh- and eighth-generation target has a launchable development foundation inside OmniCore. Wii runs homebrew DOLs through the Broadway-compatible PowerPC path. Xbox 360 and PlayStation 3 use a reusable 64-bit PowerPC execution substrate with sparse high-capacity guest memory. Wii U reuses the PowerPC family across three Espresso core objects with sparse MEM1/MEM2. Switch runs standalone NRO homebrew through a reusable AArch64 interpreter with four application-core state objects, sparse 4 GiB DRAM, and Horizon HLE foundations for service management, applet/window control, time, filesystem setup, HID shared-memory/Npad input, and VI/Binder display-layer initialization. PlayStation 4 and Xbox One remain explicitly outside the current scope; their numeric ids are reserved only to avoid future data-format collisions.

Stage 5 breadth is complete. Remaining work is compatibility depth and performance. High-end work requires:

- scalable multi-core guest scheduling;
- portable JIT/dynamic translation plus deterministic interpreter fallbacks;
- guest MMU and virtual-memory models;
- GPU command decoding and shader translation;
- WebGPU-first rendering;
- WebAssembly SIMD/threads and shared-memory workers;
- AudioWorklet-based low-latency mixing;
- user-provided lawful firmware/keys where required;
- virtual storage and multi-gigabyte disc/package streaming.

## Compatibility gate

A platform moves to `playable` only when the same OmniCore build passes deterministic unit tests plus representative legal software covering boot, CPU, graphics, sound, input, media, reset, state/persistence and sustained frame pacing.

A platform approaches a universal-compatibility claim only after a large automated corpus demonstrates it. A title merely reaching its first frame is not sufficient evidence.
